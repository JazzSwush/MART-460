# Reflection

- My design goal was to have the player go from one side to the other to reach the door to end the game. I added enemies around the map and health chests to help balance out the combat and health system. I added environments and other VFX to help create a better environment for the players to explore. I did not add to much things since I did not have the time to do so. I wanted the end point to be a bit challenging by adding a whole bunch of enemies and space for the player to run around to manuever through the enemies. It is a simple set up using the 3D game kit.
- The challenges I faced was switching scenes because I wanted a type of ending but not sure how to go about it. First, I looked at the sample levels to see how it was done but was finding it hard to comprehend. Then, I resorted to finding ways on how to do it on Youtube. I ws able to find my answer to my problem and was able to scene switch when the player enters through the door at the end. Another challenge was difuring out about checkpoints. When the player starts the game, the player wouldn't start at the point I wanted them to start, so I add to difure out how to fix that. I was able to come up with the solution by moving that destination point where the scene directs to go to. It took me a while to find because I thought it was on checkpoints, but it was a different prefab. But now, the player starts where they are meant to start, which is in the ship.
